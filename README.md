# ZANIME

**ZANIME** is an AI-powered 2D Animation Studio designed for Beginners, Content Creators, Teachers, Studios, and YouTubers.

## Overview
ZANIME aims to democratize animation by combining traditional 2D animation workflows with cutting-edge AI assistance, wrapped in a professional, commercial-grade desktop interface built on PySide6.

## Features
- Hardware Accelerated PySide6 UI
- Flexible Workspace Management (Home, Animation, Render, etc.)
- Non-Destructive Undo/Redo tracking via the Command Pattern
- Project Serialization (`.zanime` files)
- Dark and Light Themes with DPI scaling
- Extensible Plugin Architecture

## Getting Started

Run the application locally via the included launcher scripts:

**Windows Command Prompt:**
```bat
launch.bat
```

**PowerShell:**
```powershell
./launch.ps1
```

Or execute directly via Python:
```bash
python run.py
```
