# Dock System

ZANIME provides several reusable dock widgets (`QDockWidget` wrappers) that populate the periphery of the main window.

## Available Docks
1. **Property Inspector**: Renders context-sensitive UI fields (Text, Numbers, Colors, Checkboxes, Image previews).
2. **Asset Browser**: Tree categories and List/Grid views for project assets.
3. **Timeline Framework**: Playback controls, layers, and time ruler.
4. **History**: Visual representation of the Undo/Redo stack.
5. **Notification Center**: Aggregates application events (Success, Warning, Error).
6. **Preview**: Dedicated panel for real-time scene feedback.
7. **Project Explorer**: Traditional file-tree for the `.zanime` bundle.
8. **Console**: Developer debug output.
