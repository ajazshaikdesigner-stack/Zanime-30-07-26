# ZANIME v1.0 Release Notes (Genesis)

Welcome to Zanime v1.0.0, the world's most powerful AI-assisted 2D animation production suite.

## New Features
- **Integrated Editor Framework**: A powerful docking layout system.
- **AI Framework**: Advanced LLM integration for Story and Screenplay generation.
- **World Builder**: Construct sprawling environments from a massive library of 4000+ assets.
- **Animation Director**: Keyframe manipulation and layer rendering.
- **Production Renderer**: Multi-threaded FFmpeg encoding queue.
- **Interactive Tutorial**: The "Crystal Forest" demo project onboarding.
- **Performance Manager**: Strict LRU caching to ensure 100% stability on constrained hardware (AMD RX6500M / 16GB).

## Known Limitations
- The Digital Marketplace is currently architecture-only. Online purchasing is disabled.
- Advanced Battery Saver mode optimizations are slated for v1.1.

## Roadmap
- Real-time 3D Viewport support.
- Live Collaboration tools.
