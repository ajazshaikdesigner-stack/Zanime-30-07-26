# Quick Actions

The `QuickActionButton` is a specialized, borderless `QPushButton` used in the Welcome Screen.

## Design
- Inherits `QPushButton` but strips standard OS borders.
- Implements a subtle hover background (`#3a3f4b`) to feel like a modern web application or Electron app, while running natively in Qt.

## Actions
- New Project
- Open Project
- Import Project
- Recover Autosave
