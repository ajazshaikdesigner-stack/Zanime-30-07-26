# Welcome Screen

The Welcome Screen (`WelcomeWorkspace`) is the zero-state entry point for ZANIME v2. Designed to mirror professional industry standards (e.g., Blender, Unreal Engine), it provides immediate access to projects and learning materials without crowding the user.

## Layout Structure
- **Left Column**: High-level actions (New, Open, Recover) and the featured Demo Project.
- **Right Column**: Scrollable list of recent and pinned projects with an instantaneous search filter.
- **Footer**: Links to documentation and community resources.
