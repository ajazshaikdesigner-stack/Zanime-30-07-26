# Project Format (`.zanime`)

A ZANIME project is a standard `.zip` file compressed natively through Python. 

## Internal Directory Tree
```text
story/         - Text files related to story logic
script/        - Screenplay files and dialogue maps
characters/    - Generated character sprites
backgrounds/   - Background environment layers
props/         - Independent animated objects
storyboard/    - Storyboard sequence configs
scenes/        - Scene composition graphs
timeline/      - Timeline JSON configurations
voice/         - Generated AI voices (WAV/MP3)
music/         - BGMs and SFX
render/        - Final MP4 exports
cache/         - Temporary processing cache
autosave/      - project.json background backups
logs/          - Localized debug logs
exports/       - Various export targets
assets/        - Custom user-provided files
thumbnails/    - Dashboard UI thumbnails
```
