# Demo Project ("The Crystal Forest")

To ensure users have immediate assets to play with during the Interactive Tutorial, Zanime bundles a hardcoded Demo Project.

## Demo Contents
- **Title**: The Crystal Forest
- **Characters**: Zehak (Main), Lumi (Companion)
- **Duration**: 20 Seconds
- **Resolution**: 1920x1080 @ 24 FPS

The `DemoProjectManager` is responsible for instantly bootstrapping this data and injecting it into the various studio workspaces when the `TutorialWorkspace` launches.
