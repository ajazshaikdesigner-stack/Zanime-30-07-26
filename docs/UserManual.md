# Zanime User Manual

## Overview
Zanime is structured around "Workspaces". Each workspace is dedicated to a specific phase of the animation pipeline.

## Getting Started
1. **Welcome Wizard**: Upon first launch, you are greeted with the Welcome Wizard. Click "Interactive Tour" to load the built-in demo project.
2. **Settings**: Navigate to the Settings Workspace to configure your License Tier, Backup locations, and Performance thresholds.

## Workspaces
- **Story Studio**: Generate screenplays using AI.
- **Character Studio**: Manage and modify character assets.
- **World Builder**: Drag-and-drop environments.
- **Animation Director**: Edit keyframes.
- **Render**: Export to MP4 using background threads.
