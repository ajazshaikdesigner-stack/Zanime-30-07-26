# Support Guide

If you encounter issues while using Zanime, please utilize the automated Diagnostics tool.

## Generating a Crash Dump
1. Open the `Settings` Workspace.
2. Navigate to `Diagnostics & Crash Reports`.
3. Click "Simulate Crash & Send Dump".
4. Retrieve the `crash_dump.json` from your User AppData folder.

## Getting Help
For Community Support, launch the Welcome Wizard and click "Join the Community".
